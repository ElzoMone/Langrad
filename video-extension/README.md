# Langrad Video 0.5.0 — YouTube

Расширение Chrome / Edge Manifest V3. Это новая версия видеочиталки, не путать со старым расширением для импорта статей.

## Установка

1. Скачайте ZIP `https://langrad.vercel.app/langrad-video-0.5.0.zip` и распакуйте в отдельную папку.
2. В Chrome перейдите на `chrome://extensions`, включите режим разработчика.
3. Если установлена старая тестовая версия **Langrad Video v0.4.0**, выключите её, чтобы субтитры не дублировались.
4. Нажмите «Загрузить распакованное расширение» и выберите папку, содержащую `manifest.json`.
5. Откройте немецкое видео на YouTube, включите немецкие субтитры CC, обновите вкладку. Под видеосубтитрами появятся кликабельные слова.

## Функции

- Перевод и морфология слов через тот же офлайн-индекс Wiktionary/Kaikki, что использует основная Langrad: `/forms/xx.json` и `/dict/xx.json`. Шарды запрашиваются лениво (не скачиваются все).
- Слова без перевода: запрос в русский Викисловарь, если доступен. Без выдуманных переводов.
- Четыре статуса: обычное, просмотрено/неизвестное, изучается, известное — с разными типами подчёркивания.
- Частотный ранг по FrequencyWords / Hermit Dave (OpenSubtitles 2018) при доступности публичного списка. Это не уровень CEFR.
- ↶ 4 секунды назад, скорость 0,5–1,5×.
- **RU: выключен по умолчанию**. При включении текст *только текущей строки субтитров* отправляется в MyMemory. Этот внешний сервис имеет собственные условия и лимиты.
- «＋ Учить» помещает слово в очередь `chrome.storage.local`. При открытии Langrad в том же профиле браузера слова импортируются через существующий подтверждаемый протокол `LR_VIDEO_VOCAB`; ваши собственные переводы не перезаписываются.
- Статусы известных/изучаемых слов и выбранная тема Langrad копируются при открытии Langrad через новый мост `LR_VIDEO_STATUS_REQUEST` → `LR_VIDEO_STATUS`.
- Видео, звук и полный транскрипт на сервер Langrad не загружаются. Словарные запросы отправляются в домены, указанные в манифесте.

## Особенности

- Из-за изменений DOM YouTube положение карточки и субтитров может требовать доработки; не тестировалось на всех версиях плеера.
- Это не «синхронизация через аккаунт»: два браузера или разных профиля Chrome не разделяют слова автоматически.
- Для повторного получения статусов вернитесь в открытую вкладку Langrad или обновите её.
- Если свободных внешних словарей нет, будет ссылка на словарь и предложение сохранить собственный перевод.
- Личные API-ключи Gemini не используются расширением.
