# Langrad — этап 3: новый поиск в читалке

**Опубликовано 9 ноября 2026**, Vercel deployment:
\`dpl_6K7N4PPrgvb5GJQk1PPX65Yg6quV\` (production, READY).

## Изменения

- \`index.html\` изменён только добавлением:
  \`<script defer src="/reader-lexicon.js"></script>\`.
- \`reader-lexicon.js\` — отдельный независимый модуль после всех старых
  обработчиков читалки. Он не переписывает \`localStorage\`, \`IndexedDB\`
  или функции сохранения слов.
- При клике выполняется асинхронный поиск:
  1. точная запись немецкого слова в существующем \`/dict/{prefix}.json\`;
  2. Wiktionary/Simplemma индекс \`/forms/{prefix}.json\` для словоформы;
  3. все правдоподобные леммы (до 14) → подходящие записи словаря переводов;
  4. показ грамматики, исходной формы, переводов и других вариантов.
- Запросы шардов ленивые; кэш Promise/объектов внутри вкладки предотвращает
  повторную загрузку одной и той же части словаря.
- Для \`ß/ss\` и умлаутов применяется нормализация; основной поиск точный,
  орфографическая нормализация — запасной вариант.
- Русские переводы берутся только из реально существующих записей
  FreeDict/WikDict; грамматика — из Wiktionary. Для Simplemma грамматические
  признаки не придумываются. Указывается источник и лицензия.
- Пользовательский ручной перевод всегда имеет приоритет.
- Счётчик запросов защищает от отображения результата старого клика при
  переключении между словами.
- Если нет подтверждённой леммы, сохраняются старые ссылки на Wiktionary,
  ручной перевод и другие старые словарные данные.

## Проверка

Тестирование в JS DOM окружении на фактически опубликованных HTML, JS и
публичных JSON шардах:

| Форма | Найденная лемма / результат |
|---|---|
| erkannte | erkennen, Präteritum, узнавать / узнать |
| gegangen | gehen, Partizip II |
| diesen | dieser, с альтернативами diese и dieses |
| Zigaretten | **die Zigarette**, мн. ч., сигарета |
| eingenommen | einnehmen, Partizip II; FreeDict/WikDict пока без перевода |

Дополнительные тесты прошли: ручной перевод **не перезаписывается**,
повторный клик использует кэш, при быстрых кликах отображается последняя
выбранная карточка. Никаких ошибок исполнения в тесте.

Проверены живые URL — HTTP 200:
\`/\`, \`/index.html\`, \`/reader-lexicon.js\`,
\`/dictionary.json\`, \`/project.html\`,
\`/dict/er.json\`, \`/forms/er.json\`, \`/forms/manifest.json\`.

## Что намеренно не сделано

- Комбинации отделяемых приставок вроде \`kam ... an\` → \`ankommen\`.
- Онлайн-запросы в Wiktionary API с локальным кешем.
- Полный футер лицензий и комплексная регрессия.

Это запланированные этапы 4 и 5.
