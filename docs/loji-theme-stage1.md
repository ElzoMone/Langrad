# Loji // Long March — этап 1

Опубликовано 9 ноября 2026 года на https://langrad.vercel.app/.

Vercel production deployment: `dpl_DJmsVSiECKsgmDpvj9yxuceQaPcA` — READY.

## Что изменилось

- В переключателе оформления появилась третья тема **Loji — Long March / чёрно-красная**.
- Основная палитра: почти чёрный фон, бордовые панели и красные акценты;
  основной текст остаётся светлым ради читаемости.
- Шрифты: `Oxanium` для латинских заголовков, `IBM Plex Sans` для
  текста интерфейса и читалки, `IBM Plex Mono` для небольших системных меток;
  предусмотрены системные запасные шрифты.
- В верхней части шапки в Loji-теме вместо глобуса TFR отображается
  SVG-глаз с лёгкой пульсацией. Эффект отключается по
  `prefers-reduced-motion`.
- Оформлены кнопки, карточки, навигация, подсказки, грамматика и поля ввода.
- Стили определены в отдельном `loji-theme.css`, только под
  `html[data-theme="loji"]`.
- Выбранная тема сохраняется в существующем ключе `langrad-theme`.
- Прежние **classic** и **TFR** остались без изменений.
- Исправления и новые настройки системных фраз и элементы по бокам читалки
  **не включены** — они относятся к будущим этапам 2 и 3.

## Файлы

- `index.html` — регистрация темы, пункт выбора и SVG-глаз.
- `loji-theme.css` — изолированные стили Loji.
- `tests/loji-theme.cjs` — проверка сохранения темы, глаз/глобуса и
  пользовательских данных в JSDOM.
