# Исправление переводов производных форм — 9 ноября 2026

Патч к этапу 3. Production deployment:
`dpl_28gAPNQn17X7YPEuMgxcXkVXuCAF` (READY).

## Причина

Langrad обрабатывал только один переход словоформа → лемма.
Например:
- `vorgestellter → vorgestellt` — из таблицы склонения прилагательного;
- словарь FreeDict/WikDict не содержит отдельного русского перевода
  `vorgestellt`;
- однако Wiktionary знает `vorgestellt → vorstellen` (Partizip II), а
  `/dict/vo.json` уже содержит статью `vorstellen`:
  «знакомить; представлять».

## Что исправлено

Теперь `reader-lexicon.js` поддерживает до двух морфологических переходов
по подтверждённому индексу, не угадывая леммы по суффиксам. Последовательность:
точное слово → лемма → лемма следующего уровня → статья перевода.

При дополнительном переходе карточка показывает цепочку исходных форм и
отмечает, что найденное значение — **перевод исходного глагола**, а не готовый
контекстный перевод причастия. Имеющиеся грамматические признаки
показываются отдельно; ручной перевод пользователя не перезаписывается.

Исправление общее, не содержит специального правила только для
`vorgestellter`.

## Проверено

Тесты на текущем HTML и реальных публичных JSON шардах:
- `vorgestellter → vorgestellt → vorstellen` — «знакомить; представлять»;
- `vorgestellte → vorgestellt → vorstellen`;
- `erkannte → erkennen`;
- `Zigaretten → die Zigarette`;
- `gegangen → gehen`;
- `diesen → dieser`, с альтернативами.

Дополнительно проверено сохранение ручного перевода и отсутствие гонки при
быстрых кликах. Production отдаёт HTTP 200 для `/`,
`/reader-lexicon.js`, `/dictionary.json`, `/forms/vo.json`,
`/dict/vo.json`, `/project.html`. Старые файлы сайта сохранены без
изменений, кроме JS-модуля поиска.

## Ограничение

Это исправление **не расширяет** пока 26 301 переводную запись.
Индекс словоформ гораздо шире русского словаря. Для новых переводов
по-прежнему нужен отдельный этап расширения DE–RU источников или
проверяемый онлайн-fallback, с соответствующей атрибуцией.
