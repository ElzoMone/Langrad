# Langrad — этап 4: отделяемые глаголы и резервный Wiktionary API

**Опубликовано 9 ноября 2026.** Vercel production deployment:
`dpl_Ccthpog6AJpgnQZ91ZzRKCSKjzS4`, статус READY,
основной домен: https://langrad.vercel.app/.

## 1. Отделяемые приставки

В модуле `reader-lexicon.js` добавлено определение контекстного кандидата.
Если слово является подтверждённой формой немецкого глагола, последним словом
предложения/части предложения является потенциально отделяемая приставка,
а составной инфинитив **существует в офлайн-словаре**, карточка показывает
это толкование с оговоркой, что контекст может иметь несколько чтений.

Контрольные случаи:
- `Er kam gestern spät an.` → `ankommen` — прибывать/приезжать.
- `Sie rief ihren Freund an.` → `anrufen` — звонить/позвать.
- `Er kam an den Bahnhof.` → обычное `kommen`, а не `ankommen`.
- Наличие слова в словаре является свидетельством существования инфинитива,
  но **не** гарантией правильности контекстного разбора: показываем оговорку.

Алгоритм работает при нажатии на **форму глагола**; нажатие на отделённую
частицу отдельно пока не объединяет глагольную конструкцию.

## 2. Русский Викисловарь как резервный источник

- Если офлайн-поиск не дал **русского значения** и пользователь не записал
  собственный перевод, клиент обращается к публичному MediaWiki Action API
  Русского Викисловаря:
  `https://ru.wiktionary.org/w/api.php`
- Параметры: `action=query`, `prop=revisions`, `rvslots=main`,
  `rvprop=content`, `formatversion=2`, `origin=*`.
  Этот режим допускает анонимные CORS-запросы.
- Используются только реальные строки определений в немецкоязычном разделе
  статьи (`{{-de-}}` → «Значение»), без генерации перевода.
- Внешний вики-текст очищается и отображается только через `textContent`,
  без вставки HTML.
- Автоматически показываются не более трёх значений и ссылка на исходную
  статью. Указывается «Русский Викисловарь — CC BY-SA 4.0».
- Если API недоступен или статья отсутствует, старые словарные данные,
  собственный перевод и ссылки остаются доступными.
- Офлайн-результат показывается сразу, без ожидания сетевого поиска.

## 3. Кеш и сохранность данных

Новый отдельный ключ `localStorage`: `langrad-wiktionary-ru-v1`.
В нём сохраняются только результаты API, не текст пользователя и не
пользовательские словарные записи.

- Кеш положительных результатов: 14 суток.
- Кеш пустого ответа: 24 часа.
- Максимум 100 записей, старые удаляются при обновлении.
- Ошибки сети не кешируются.
- Запрос ограничен 9 секундами на статью (до трёх попыток для разных
  подтверждённых лемм).
- `langrad-v01`, другие ключи прогресса и IndexedDB **не меняются**.
- Статус «Учить», «Я знаю» и сохранённые личные переводы сохраняются.

## 4. Тесты

На реальных API и опубликованных JSON шардах проверены:
- отделяемые глаголы `kam ... an`, `rief ... an`;
- отрицательный пример `kam an den Bahnhof`;
- `unbändig` — в русском Викисловаре «неукротимый, необузданный,
  буйный, бурный»;
- повтор `unbändig`: второй вызов взят из `localStorage`;
- личный перевод пользователя не перезаписан;
- прежние `erkannte → erkennen` и `Zigaretten → die Zigarette` работают.

Проверка production по HTTP: 200 для `/`, `/reader-lexicon.js`,
`/dictionary.json`, `/dict/an.json`, `/forms/ka.json`,
`/forms/er.json`, `/forms/manifest.json` и `/project.html`.

Оригинальный `index.html` и исходные файлы сайта остались неизменными;
обновлён только `reader-lexicon.js`.
