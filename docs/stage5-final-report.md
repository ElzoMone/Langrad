## Атрибуция

Футер содержит ссылки на:

1. **FreeDict / WikDict DE–RU**, CC BY-SA 3.0 Unported — локальный файл `/dictionary-license.txt`, исходный словарь 26 301 запись.
2. **Wiktionary / Kaikki / Wiktextract**, CC BY-SA 4.0 — `/forms/SOURCES.txt`, офлайн-индекс форм 639 489 словоформ.
3. **Simplemma 1.2.0**, MIT — резервный источник пар «словоформа → лемма».
4. **Русский Викисловарь**, CC BY-SA 4.0 — резервный поиск русских значений через публичный API.

Ссылки ведут к реальным опубликованным источникам; лицензии не заменены и
не смешаны. Исправлено неточное утверждение об «исключительно локальной
обработке»: личные данные сохраняются в браузере, но отдельное неизвестное
слово может передаваться в API Русского Викисловаря для поиска значения.

Для футера добавлены правила оформления в классической и TFR-темах,
мобильный перенос ссылок и видимый фокус для клавиатурной навигации.

## Автоматизированная регрессионная проверка

Тест: `tests/reader-regression.cjs` (JSDOM 26.1.0).

Запуск из корня репозитория:

```bash
npm install --no-save jsdom@26.1.0
node tests/reader-regression.cjs
```

Это сетевой интеграционный тест: он обращается к действующему
`langrad.vercel.app`, его шардам, а для неизвестного слова — к
`ru.wiktionary.org`. Сбой внешнего API может привести к провалу
соответствующего теста без неисправности Langrad.

## Важные ограничения

- **26 301 запись перевода** — не полное покрытие немецкого языка.
  **639 489 словоформ** — это индекс морфологии, а не столько же переводов.
- Парсинг отделяемых приставок контекстный и эвристический; нельзя
  считать его полноценным синтаксическим анализатором.
- Внешний API требует сети и может не найти статью.
- Регрессионный тест работает в JSDOM; отдельного полного браузерного
  тестирования адаптивной вёрстки, TTS, импорта файлов и произвольной
  адаптации текста эта проверка не заменяет.
- Шарды предоставляются через Vercel CDN rewrite на закреплённые коммиты
  GitHub, потому что GitHub-интеграция Vercel проекта пока не подключена.
  Этот способ обеспечивает текущую доступность, но имеет зависимость от
  доступности upstream GitHub.
