# Решения по книжной библиотеке Langrad

## Этап 1

- Langrad — статическое приложение на HTML/CSS/JS. Читалка и словарь работают с `state.text` и записями `state.library`, позиции хранятся в `state.readingPages`. Эти схемы пока используются без миграции.
- `books/text-pipeline.js` обрабатывает извлечённый текст или байты TXT. Node использует CommonJS, браузер может подключить скрипт после `reader-pagination.js`. Частотный набор передаёт вызывающий код. Для него в репозитории есть `books/de-frequency.txt`.
- `processText(input, {title, author, commonWords, pageWords})` возвращает метаданные текста и главы с предварительной разбивкой. Порядок глав начинается с нуля. Позиции страниц — UTF-16 offsets, как в читалке. Размер по умолчанию — 245 слов с теми же правилами переноса, что в текущей читалке. Страницы вычисляемые, поэтому постоянному хранилищу достаточно текста главы и её метаданных.
- Определение языка эвристическое. `und` означает, что данных недостаточно. Для некоторых письменностей возвращается код без языка, например `und-Cyrl`. CEFR оценивается для немецкого текста по немецким словоформам и длине предложений. У коротких и ненемецких текстов оценка может отсутствовать. В интерфейсе оценку следует помечать знаком ≈.
- Чистка ориентируется на распознаваемые маркеры и разметку. Сомнительные OCR-искажения не исправляются автоматически. Заголовок и автор передаются отдельно, SHA-256 вычисляется по их нормализованным значениям. Такой ключ может совпасть у разных изданий одной книги.
- В этапе 1 нет хранилища книжных файлов и публичного каталога книг. Существующее хранилище браузера не предоставляет серверной идентификации владельца. На этапе 2 нужна нормальная авторизация или серверная сессия владельца для приватных запросов. Значение из localStorage само по себе не подтверждает права доступа.
- Решение о публикации принимает автоимпорт на этапе 3 по метаданным автора, лицензии и источника. Наличие маркеров Gutenberg и результат обработки текста сами по себе не дают разрешение на публикацию.

Проверка из корня репозитория: `node --test tests/book-text-pipeline.cjs`.
